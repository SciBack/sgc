# Guías de prueba del SGC

Material para **probar** el sistema, no para usarlo: preparación, recorrido de punta a punta, una
guía por rol (`roles/`), un guion por flujo con sus casos negativos (`flujos/`), regresión y cómo
reportar un hallazgo. Hasta la 1.7.1 se publicaban dentro del manual; desde la 1.7.2 el manual
publicado es solo de usuario y estas guías quedan aquí.

Siguen vigiladas: `docs-site/src/data/coverage.json` declara un rol y un flujo por página, y la
verificación del manual (`npm run verify` en `docs-site/`) falla si falta alguna o si su fuente
en el código ya no existe.

Los enlaces entre estas páginas conservan el formato del sitio en el que se publicaban
(`../../flujos/…/`), así que en GitHub no todos resuelven.
